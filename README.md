# Animated Background

A beautiful, modern animated background with floating gradient orbs and interactive mouse-tracking effects.

## 🚀 Live Demo

Visit the deployed site: [animated-background3 Demo](https://retro-disco-ball.github.io/animated-background3/)

## Features

✨ **Smooth Gradient Animations** - Flowing color transitions with blurred gradient orbs  
🎯 **Interactive Effects** - Orbs respond to mouse movement  
📱 **Responsive Design** - Works perfectly on desktop and mobile devices  
🚀 **Performance Optimized** - Uses CSS animations for smooth 60fps performance  
🎨 **Modern Aesthetic** - Contemporary color scheme with vibrant gradients

## Files

- **index.html** - Main HTML structure
- **styles.css** - All styling and CSS animations
- **script.js** - Interactive JavaScript enhancements
- **README.md** - This file

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Move your mouse around to interact with the animated orbs

## Customization

### Change Colors
Edit the gradient colors in `styles.css` in the `.orb-1`, `.orb-2`, `.orb-3`, and `.orb-4` classes.

### Adjust Animation Speed
Modify the animation duration values (e.g., `15s`, `18s`, `20s`) in the `.orb-*` animation properties.

### Modify Orb Size
Change the `width` and `height` properties of each `.orb-*` class.
